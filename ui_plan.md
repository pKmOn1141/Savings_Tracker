## Main Page Layout: Side bar (contains list of accounts, and a button to open new account creation form)
- Sidebar (contains list of accounts, and a button to open new account creation form) - Takes 1/5 of screen space
- Main Content: If an account isnt selected, it shows the total balance for each account, and the combined total for all
- Main Content: If an account is selected, it will show more information per account, including the total balance, profit and deposit variables, as well as a table of all entries
- Main Content: When an account is selected, the user will see a button that allows them to enter a new entry, which will open the form on the same page

## UI Design
- The top banner shouldnt be too big, saying "Overview" when no account is selected, and saying "Account Name" for the selected account
