General aims:
1 - home screen, shows overall networth + total amount in each account
2 - option to make more accounts
3 - each account has a directory, holding csv files
4 - from home screen, a menu that shows every account (extracted from a csv file)
5 - when on each accounts page - shows a table of all deposits, total amount, total profit etc
6 - option to add a new deposit, taking info like: date, deposit amount, current account balance
7 - from this, the table will also calculate and show the increase/decrease from last month in £ and %

CSV files:
Each account has a directory, inside includes different csv files that contain:
1 - information about the account
2 - deposits
3 - optionally, other information

Moreover, there will be a general csv file that contains the names of all the accounts, as well as their last balance
All calculations will be saved to the csv files to make loading quicker, itll only be updated when a new deposit is added to that account
